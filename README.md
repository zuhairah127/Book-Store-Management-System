# Book Store Management System

A Java-based Book Store Management System developed to demonstrate the practical implementation of Object-Oriented Programming (OOP) concepts in a console-based application.

## Project Overview

The system provides separate functionalities for administrators and customers. Administrators can manage book inventory, customer records, transactions, and sales reports, while customers can browse books, place orders, make payments, and view their purchase history.

## Key Features

### Admin
- Add, update, and remove books
- View book inventory
- Manage customer information
- View transaction records
- Generate sales reports

### Customer
- Browse available books
- Search for books
- Place book orders
- Select payment methods
- View purchase history

## Programming Concepts

The project applies core Object-Oriented Programming concepts, including:

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Constructors and Methods
- ArrayList and Data Management

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Console-Based Application
